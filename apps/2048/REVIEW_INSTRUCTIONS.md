# Review 지침: apps/2048

## 범위
- 이 지침이 허용하는 범위는 오직 `D:\ClaudeCode\my-blog\apps\2048\` 폴더 내부뿐이다.
- 블로그의 다른 파일은 절대 수정하지 않는다.
- 문제를 발견하면 이 폴더 안에서 직접 수정해도 된다 (범위 내에서는 Edit/Write 허용).

## 할 일
1. `apps/2048/spec.md`를 읽고 사양을 파악한다.
2. `apps/2048/index.html`, `style.css`, `script.js` 코드를 사양과 대조해 검토한다 — 특히 이동/병합 알고리즘의 정확성(체인 병합 방지, 유효하지 않은 이동 시 타일 미생성), 점수 계산, 승패 판정 로직.
3. 브라우저에서 실제로 동작을 검증한다:
   - 로컬 정적 서버로 `apps/2048/`을 서빙해서 열어본다 (Node.js는 `C:\Program Files\nodejs\node.exe`에 있으나 PATH에 없으므로 전체 경로로 실행해야 한다. 간단한 정적 서버가 필요하면 `python -m http.server` 또는 Node 내장 http 모듈로 임시 스크립트를 만들어 써도 되지만, 그 임시 서버 스크립트는 apps/2048/ 바깥에 만들지 말고 스크래치 디렉터리 등에 만들 것).
   - 방향키 4방향 이동, 터치/스와이프 이동(가능하면), 점수 증가, 최고점수 localStorage 저장/유지, 승리(2048 타일) 및 패배(더 이상 이동 불가) 오버레이, 재시작 버튼 동작을 확인한다.
   - 모바일 뷰포트(예: 375px)에서 레이아웃이 깨지지 않는지 확인한다.
   - 콘솔 에러가 없는지 확인한다.
4. 문제를 발견하면 apps/2048/ 안의 파일을 직접 고치고, 고친 뒤 다시 확인한다.
5. 결과를 `apps/2048/review.md`로 작성한다: 검증한 항목들, 발견한 문제와 수정 여부, 최종 결론(정상 동작 여부).
