# Build 지침: apps/2048

## 범위
- 이 지침 파일이 허용하는 범위는 오직 `D:\ClaudeCode\my-blog\apps\2048\` 폴더 내부뿐이다.
- 블로그의 다른 파일(`src/`, `scripts/`, `posts/`, `dist/`, 루트의 `CLAUDE.md` 등)은 절대 수정하지 않는다.
- 새 npm 패키지, 빌드 도구, 외부 CDN 라이브러리를 추가하지 않는다 (순수 HTML/CSS/JS).

## 구현 대상
`apps/2048/spec.md`에 적힌 계획을 그대로 구현한다. 계획을 먼저 읽고 그 사양(파일 구성, 상태 모델, 이동 알고리즘, 입력 처리, 점수판, 승패 판정, 레이아웃)을 충실히 따른다.

만들 파일:
- `apps/2048/index.html`
- `apps/2048/style.css`
- `apps/2048/script.js`

## 완료 기준
- `index.html`을 브라우저에서 `file://`로 직접 열어도 동작해야 한다 (서버/빌드 불필요).
- 방향키 4방향 이동 + 병합, 터치 스와이프 이동, 점수/최고점수 표시, 승리/패배 오버레이 + 재시작이 모두 동작해야 한다.
- spec.md의 "수동 테스트 체크리스트" 항목을 스스로 코드 리뷰 수준에서 점검한다(체인 병합 방지, 유효하지 않은 이동 시 타일 미생성 등 로직 정확성 위주). 실제 브라우저 검증은 별도의 Review 단계에서 진행하므로 여기서는 로직이 사양과 정확히 일치하는지에 집중한다.
