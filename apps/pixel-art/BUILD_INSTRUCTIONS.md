# Build 지침: apps/pixel-art

## 범위
- 이 지침이 허용하는 범위는 오직 `D:\ClaudeCode\my-blog\apps\pixel-art\` 폴더 내부뿐이다.
- 블로그의 다른 파일(`src/`, `scripts/`, `posts/`, `dist/`, `apps/2048/`, 루트의 `CLAUDE.md` 등)은 절대 수정하지 않는다.
- 새 npm 패키지, 빌드 도구, 외부 CDN 라이브러리를 추가하지 않는다 (순수 HTML/CSS/JS).

## 구현 대상
`apps/pixel-art/spec.md`에 적힌 계획을 그대로 구현한다. 계획을 먼저 읽고 사양(렌더링 방식, 데이터 모델, 입력 처리, 팔레트, PNG 내보내기, 레이아웃)을 충실히 따른다.

만들 파일:
- `apps/pixel-art/index.html`
- `apps/pixel-art/style.css`
- `apps/pixel-art/script.js`

참고용으로 `apps/2048/`의 기존 파일들을 열어봐도 되지만(스타일 톤 참고), 그 파일들을 수정하지는 않는다.

## 완료 기준
- `index.html`을 브라우저에서 `file://`로 직접 열어도 동작해야 한다.
- 마우스 클릭/드래그, 터치 탭/드래그로 칸을 칠할 수 있어야 하고, 빠르게 드래그해도 중간 칸이 빠지지 않아야 한다(Bresenham).
- 지우개는 흰색이 아니라 투명 처리.
- 팔레트 프리셋 + 커스텀 컬러 피커 + 전체 지우기(확인창) 모두 동작.
- PNG로 저장 시 실제 16x16 픽셀, 알파 채널이 살아있는 파일이 다운로드되어야 한다.
- spec.md의 "수동 테스트 체크리스트"를 스스로 코드 리뷰 수준에서 점검한다. 실제 브라우저 검증은 별도의 Review 단계에서 진행하므로 여기서는 로직이 사양과 정확히 일치하는지에 집중한다.
